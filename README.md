# Seed Co Vegetables

Create a complete Seed Co Zambia Vegetables https://seedcogroup.com/zm/vegetables website using the live Seed Co Zambia Vegetable site as the source for ALL existing content, pages, products and navigation.

Use the Seed Co Group website at http://139.84.241.235/scg/ as the primary brand reference. Keep the Seed Co identity, branding, colours, typography and overall visual language consistent with the Group, but do NOT make the design feel like a basic copy of the Group website.

Be creative with the Vegetable experience. Introduce a fresh, modern and visually engaging agricultural aesthetic that feels energetic, premium and distinctive while still clearly belonging to Seed Co.

DESIGN DIRECTION:

- Modern, clean and professional
- Fresh, vibrant and premium vegetable/agriculture feel
- Creative use of vegetable/crop imagery, shapes, layouts and visual storytelling
- Strong typography and generous whitespace 
- Interesting product presentation and interactive cards 
- Subtle animations, hover effects and micro-interactions
- Strong visual hierarchy and engaging CTAs
- Fully responsive across desktop, tablet and mobile

IMPORTANT:

- Preserve ALL existing live-site content and information architecture.
 - Recreate every available page, product/category page and supporting page.
- Make every navigation item, button, card and CTA functional. 
- Every link must lead to the correct equivalent page in the redesigned website.
- No dead links, placeholders or missing pages.

Build the Vegetable website as a reusable Seed Co COUNTRY VEGETABLE TEMPLATE that can later be adapted for other African countries by changing country-specific products, content and imagery.

The final result should feel fresh and exciting rather than boring, while remaining unmistakably Seed Co and consistent with the Group brand.
